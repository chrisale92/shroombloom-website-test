# ShroomBloom Product Page

GitHub Pages upload package for the Nublume ShroomBloom product page.

## Files to upload
Upload everything in this folder to the root of your GitHub repository:

- `index.html`
- `nublume-shroombloom-product-page-brandguide-assets/`

## GitHub Pages
In GitHub, go to **Settings → Pages**, choose your branch, and set the folder to `/root`.
